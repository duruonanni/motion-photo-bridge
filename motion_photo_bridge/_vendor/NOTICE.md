# Vendored: android-motion-photo-merger 1.5.0

`vivo_motion_photo/` is a verbatim copy of
[oneone1995/android-motion-photo-merger](https://github.com/oneone1995/android-motion-photo-merger)
(MIT, see `vivo_motion_photo/LICENSE`).

It is vendored so `pip install` needs no git, no network beyond PyPI, and no
separate install step. Upstream is unmodified; the only difference is this
folder name. If you need a newer merger, replace the folder wholesale.
